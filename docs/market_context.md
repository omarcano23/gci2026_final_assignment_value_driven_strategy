## Elección narrativa provisional
Usar una sola slide de contexto con 2–3 datos que apoyen el caso finalmente elegido. Si se elige monetización, priorizar ARPU/precios; si retención, churn/portabilidad; si CX, calidad y costos. Los benchmarks actuales no calibran datos históricos; no mezclar tasas mensuales y proporciones de muestra. No usar PIB como TAM. CTIA es asociación sectorial, SEC reportes corporativos y FCC fuente regulatoria. No afirmar crecimiento de ingresos de Company A. No se ha estimado el tamaño de mercado monetario; no necesario para valorar base existente, revisar si caso requiere TAM.
